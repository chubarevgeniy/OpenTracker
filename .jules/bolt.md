## 2025-02-18 - Preserve Referential Equality for React.memo
**Learning:** When passing nested state defaults (like `{ breakfast: [], lunch: [], dinner: [], snack: [] }`) as props to `React.memo` components, allocating the fallback object inside the parent component breaks memoization on every render, causing expensive re-renders across all child instances even when unrelated state changes (e.g., keystrokes in a sibling input).
**Action:** Always extract static fallback objects to constants outside the component definition to ensure referential equality is maintained when the state object is falsy/undefined.
